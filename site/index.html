I Overview

What Is This Kit?

Medal of Honor: Allied Assault was released in 2002 and remains one of the finest World War II shooters ever crafted — its Omaha Beach sequence a milestone of interactive storytelling. The game went dark on modern hardware for years. Then OpenMoHAA arrived: a faithful, community-built open-source engine revival that breathes full life back into this classic.

The OpenMoHAA Server Kit runs a MOHAA dedicated server with Docker Compose. Every setting lives in one .env file. It runs on a laptop, a home server or any Linux VPS, on amd64 or arm64. It ships no game data: you bring your own copy of the game.

III Installation

Getting the Game & Engine

Two prerequisites: the original game files (GOG) and, to play, the OpenMoHAA engine release. The Docker server only needs the game files; it downloads its own copy of OpenMoHAA.

ⓘ Note — Legal

You must obtain the original MOHAA game files yourself via a legitimate purchase (GOG.com). This kit contains no game data and never downloads it. It does not distribute or reproduce any copyrighted game content.

1
Purchase & Download from GOG

Buy on GOG — Medal of Honor: Allied Assault War Chest

Create an account on GOG.com and purchase Medal of Honor: Allied Assault War Chest.

Navigate to Account → Games and scroll to Download offline backup game installers. Download the installer .exe and all of its .bin parts into one folder:

  • setup_medal_of_honor_<version>.exe
  • setup_medal_of_honor_<version>-1.bin, -2.bin, …

The exact names depend on the installer version GOG gives you; the commands below match any of them.

2
Extract Game Files

Run the .exe installer and install the game into a folder (e.g. C:\Games\mohaa).

Install innoextract and run:

brew install innoextract
innoextract --gog setup_medal_of_honor_*.exe

Or use Docker (nothing to install on the host):

docker run --rm -v "$PWD":/data -w /data debian:stable-slim \
  bash -c "apt-get update -qq && apt-get install -y -qq innoextract \
           && innoextract --gog setup_medal_of_honor_*.exe \
           && chown -R $(id -u):$(id -g) app"

Rename the resulting app folder to mohaa.

Install innoextract via your package manager, or run it in Docker:

docker run --rm -v "$PWD":/data -w /data debian:stable-slim \
  bash -c "apt-get update -qq && apt-get install -y -qq innoextract \
           && innoextract --gog setup_medal_of_honor_*.exe \
           && chown -R $(id -u):$(id -g) app"

Rename the resulting app directory to mohaa.

3
Download OpenMoHAA

Visit the OpenMoHAA releases page and download the latest release (v0.82.1 or newer) for your platform:

Windows x64 openmohaa-v0.82.1-windows-x64.zip macOS Universal openmohaa-v0.82.1-macos-multiarch…zip Windows ARM64 openmohaa-v0.82.1-windows-arm64.zip Linux x64 openmohaa-v0.82.1-linux-amd64.zip Linux ARM64 openmohaa-v0.82.1-linux-arm64.zip

Extract the zip directly into your mohaa game directory.

4
Prepare for Execution

Nothing extra required — extract and play.

From the game directory, remove quarantine flags and make files executable:

xattr -rd com.apple.quarantine ./ 2>/dev/null || true
chmod +x launch_openmohaa_* omohaaded openmohaa

The xattr line is macOS-only (safely ignored on Linux). chmod +x applies to both.

VI Quickstart

Local Docker Quickstart

You need Docker with Compose, and your GOG installer or an installed copy of the game. Everything is driven by a single .env file.

Fig. VI-A — Your own game files and one .env file feed a hardened container

1
Get the Kit & Configure
git clone https://github.com/a-magdy/openmohaa-server-kit.git
cd openmohaa-server-kit
cp .env.example .env        # set SERVER_HOSTNAME, RCON_PASSWORD, maps...

Every setting is documented in .env.example.

2
Prepare Your Game Files

Copies pak*.pk3 from your own copy into ./game/main (and mainta/, maintt/ for the expansions). Keep the installer's .bin parts next to the .exe:

./scripts/prepare-game-files.sh --source ~/Downloads/setup_medal_of_honor_*.exe
#   or: --source "/path/to/installed/Medal of Honor Allied Assault"
3
Start & Check
docker compose up -d
python3 rcon/rcon-status.py 127.0.0.1

Players join with connect <your-ip>:12203 in the console, or through the in-game server browser when PUBLIC_LISTING=1.

VII Hosting

Hosting a Dedicated Server

Works on any Linux VPS or home server with Docker: Hetzner, DigitalOcean, OVH, a Raspberry Pi 4/5 with a 64-bit OS, and so on. Up to ~30 players and bots run comfortably on 1 vCPU and 1 GB RAM. Pick a region close to your players; ping matters more than CPU. Full guide: hosting/vps.md.

1
Install Docker & Open the Ports

Follow Docker's install guide, then open both UDP ports in your provider's firewall:

sudo ufw allow 12203/udp   # game traffic (GAME_PORT)
sudo ufw allow 12300/udp   # GameSpy browser queries (GAMESPY_PORT)
2
Get the Kit on the Server
git clone https://github.com/a-magdy/openmohaa-server-kit.git
cd openmohaa-server-kit
cp .env.example .env
nano .env   # hostname, RCON password, game type, maps
3
Upload Your Game Files

Prepare them on your own computer, then copy them up over SSH:

# on your computer, in your local clone
./scripts/prepare-game-files.sh --source ~/Downloads/setup_medal_of_honor_*.exe
./scripts/upload-game-files.sh user@your-server
4
Start, Check & Update
docker compose up -d
docker compose logs -f              # Ctrl+C to stop following
python3 rcon/rcon-status.py <server-ip>
git pull
docker compose pull     # or: docker compose build
docker compose up -d

Pin KIT_VERSION in .env to a release (for example 0.1.0) to update only when you choose.

Key Settings

SERVER_HOSTNAME
Name shown in the server browser.
RCON_PASSWORD
At least 8 characters, no spaces, not changeme. Empty turns RCON off.
GAME_TYPE
1 FFA, 2 Team, 3 Round, 4 Objective, 5 Tug-of-War, 6 Liberation.
MAP_ROTATION
Space-separated maps, e.g. dm/mohdm1 dm/mohdm2.
MAX_CLIENTS / MAX_BOTS
Players and bots; the sum must be 64 or less.
GAME_TARGET
0 Allied Assault, 1 Spearhead, 2 Breakthrough.

The full table is in the README. Anything else goes in custom/custom.cfg; start from custom.cfg.example.

⚠ Warning — Firewall & RCON

Docker publishes ports past ufw rules on its own, so the provider firewall is the one that counts. RCON uses the game port: anyone who can reach it can try passwords, so use a long RCON_PASSWORD or leave it empty.

IX Frequently Asked Questions

FAQ

Common questions and troubleshooting. Full docs in docs/faq/.

Windows: %APPDATA%\openmohaa

Mac: ~/Library/Application Support/openmohaa

Linux: ~/.openmohaa

See docs/faq/config-paths.md.

Server (this kit): put the .pk3 in custom/, add its map name to MAP_ROTATION in .env, and run docker compose up -d.

Client: put it in the main subdirectory of your OpenMoHAA config folder.

If the paths inside the .pk3 start with main/, it was packed one level too deep; see custom/README.md.

Go to Settings → Advanced and enable the Console checkbox, or add seta ui_console "1" to omconfig.cfg. Also check your keyboard layout — the ~ key mapping may differ.

Remove the quarantine flag and make files executable:

xattr -rd com.apple.quarantine ./
chmod +x launch_openmohaa_* omohaaded openmohaa

Set MAX_BOTS and either BOT_COUNT (fixed number) or BOT_FILL_MIN_PLAYERS (fill up to that many players) in .env. MAX_CLIENTS + MAX_BOTS must be 64 or less. With RCON on you can also run rcon addbot 5 or rcon exec bots.cfg from the in-game console.

Run docker compose logs openmohaa. The kit checks your settings and game files before starting and says what's wrong, for example a missing pak0.pk3 or an RCON_PASSWORD that is too short.

docker compose ps                         # healthy?
sudo ss -ulnp | grep -E ':(12203|12300)'
python3 rcon/rcon-status.py <server-ip>
nmap -sU -p 12203,12300 <server-ip>

Check that both UDP ports are open in your provider's firewall. See docs/faq/troubleshooting.md.

Set DOWNLOAD_URL in .env to a public HTTP(S) location serving your custom .pk3 files. See docs/faq/nginx-downloads.md and docs/faq/download-validation.md.
